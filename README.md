# بات گزارش قیمت (price-report-bot)

بات تلگرامی برای گزارش **تخفیف فیک** و **قیمت بالاتر از بازار** در دیجی‌کالا، با مقایسه خودکار با ترب و تأیید تیم در یک گروه ادمین. کاملاً رایگان، روی GitHub Actions.

## فلو

1. کاربر لینک کالای دیجی‌کالا را می‌فرستد و نوع گزارش را انتخاب می‌کند (تخفیف فیک / جای دیگر ارزان‌تر + مدرک اختیاری).
2. بات خودکار بررسی می‌کند:
   - **ارزان‌تر:** کمترین قیمت فروشنده‌های معتبر ترب (لیست سفید، امتیاز بالا یا ۱+ سال سابقه).
   - **تخفیف فیک:** قیمت قبل از تخفیف در برابر تاریخچه قیمت و قیمت رایج بازار.
   - ضد تقلب: سقف روزانه، جلوگیری از گزارش تکراری، مورد تأییدشده‌ی اصلاح‌نشده دوباره پاداش نمی‌گیرد.
3. کارت گزارش با آیدی کاربر و شواهد به گروه ادمین می‌رود: ✅ درست / ❌ نادرست (با دلیل) / 🔁 بررسی مجدد.
4. بعد از ✅: انتخاب وچر از یکی از استخرها، تایپ کد دستی، یا بدون وچر ← پیام و کد برای کاربر.
5. 🔧 اصلاح شد ← پیام اصلاح قیمت برای کاربر.
6. 💬 پاسخ به کاربر: با تمپلیت‌های تعریف‌شده توسط ادمین، پیام آزاد، یا Reply مستقیم روی کارت. جواب کاربر زیر همان کارت برمی‌گردد.
7. همه پیام‌های خودکار بات (خوش‌آمد، ثبت، تأیید، رد، وچر، اصلاح، سقف روزانه) از داخل گروه ادمین قابل ویرایش‌اند.

سقف گزارش: 5 گزارش برای هر کاربر در هر روز (تقویم تهران) — قابل تغییر در `config.json`.

راهنمای قدم‌به‌قدم راه‌اندازی: [GUIDE.md](GUIDE.md)

## ساختار

| مسیر | کار |
|---|---|
| `bot/handlers.py` | فلوی کاربر و گروه ادمین |
| `bot/checker.py` | بررسی خودکار و حکم اولیه |
| `bot/sources/` | خواندن دیجی‌کالا و ترب |
| `bot/state.py` | ذخیره وضعیت در ریپوی خصوصی |
| `config.json` | آستانه‌ها، لیست سفید فروشنده‌ها، دلایل رد، سقف‌ها |
| `.github/workflows/bot.yml` | اجرای بات (هر اجرا ۵۵ دقیقه، اجرای بعدی را خودش شروع می‌کند) |
| `.github/workflows/selftest.yml` | تست دسترسی به تلگرام، دیجی‌کالا و ترب |

## تنظیمات گیت‌هاب

**Secrets:** `BOT_TOKEN`، `ADMIN_GROUP_ID`، `STATE_SSH_KEY` (کلید دسترسی فقط به ریپوی state)
**Variables:** `STATE_REPO` (مثلاً `ehsan-Moeininejad/price-report-bot-state`)، `BOT_ENABLED` (برای خاموش کردن: `false`)

دیتای کاربران و کدهای وچر فقط در ریپوی **خصوصی** state ذخیره می‌شود؛ این ریپو می‌تواند عمومی بماند.

## دستورات گروه ادمین

`/stats` · `/open` · `/templates` · `/settpl` · `/deltpl` · `/reasons` · `/pools` · `/addpool نام | توضیح` (کدها خط‌به‌خط یا فایل CSV/TXT/XLSX با همین کپشن) · `/delpool نام` · `/check لینک` · `/msg آیدی متن` · `/ban آیدی` · `/unban آیدی`
